## 📋 Standard Lecture Summary Framework

To eliminate clutter and maintain consistency, every lecture summary follows this exact layout (see [templates/lecture-summary-template.md](templates/lecture-summary-template.md)):

1. **Header**: Date, Video Title, YouTube Link, Key Focus.
2. **Core Algorithmic Thesis**: What is the algorithm delivering price to and why?
3. **Time & Price Elements**: Specific Macro windows, Killzone context, Sessions.
4. **PD Arrays Highlighted**: Fair Value Gaps (FVG), Order Blocks (OB), Breakers, Volume Imbalances (VI).
5. **Chart Examples & Markups**: Key timestamps, schematic setups.
6. **Actionable Checklist**: Direct rules for the trading journal and live execution.
