# ICT Trading Notes

A comprehensive repository for Inner Circle Trader (ICT) concepts, market structure analysis, core models, and trading execution logs.

---

## 📌 Core Concepts Overview

- **Market Structure & Order Flow**
  - Break of Structure (BOS) vs. Market Structure Shift (MSS)
  - Swing Highs & Lows / Liquidity Pools (BSL / SSL)
  - Premium & Discount Arrays (PD Arrays)

- **Imbalances & Inefficiencies**
  - Fair Value Gaps (FVG) & Volume Imbalances (VI)
  - Balanced Price Ranges (BPR)
  - Liquidity Voids

- **Institutional Reference Points (PD Arrays)**
  - Order Blocks (Bullish / Bearish OB)
  - Breaker Blocks & Mitigation Blocks
  - Rejection Blocks & Propulsion Blocks

- **Time & Price Theory**
  - Power of 3 (AMD: Accumulation, Manipulation, Distribution)
  - Session Killzones (Asian, London, New York AM/PM)
  - ICT Macro Time Windows
  - True Day Open (00:00 NY / 08:30 NY)

- **Entry Models & Execution**
  - ICT 2022 Mentorship Model
  - Silver Bullet Model
  - Judas Swing setups
  - Daily Bias determination
